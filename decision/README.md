# RMTC C++ 决策模块 v0.2

2026-10-23新增v1.1战斗收益整合：普通攻击贡献分摊、击杀收益估计、死亡额度损失及存活任务门槛。实现与验证边界见 [B部分交接](../docs/STRATEGY_HANDOVER.md)。旧场景通过记录不代表本次改动已回归通过。

这个模块接收已经整理好的本车状态、资源、任务和敌人信息，返回当前回合的一个动作，并说明选择原因。用户负责决策，队友负责底座；现已与本仓库新建的 `rmtc_ws/src/rmtc_bot/` 接通，尚未与队友可能另有的本地源码合并。

默认使用任务采集型，另外提供进攻型和生存型。三种模式共用规则判断和寻路接口。用户已授权开始实现；具体权重仍是第一版经验值，需要后续比赛场景调优。

## 已实现

- 第一阶段按资源价值和路径距离选目标；无已知资源时使用底座提供的探索目标。地图尺寸来自输入，不写死路线。
- 第二阶段综合任务与资源的收益，识别裁判报告的任务完成 ID；支持到点、普通/高价值资源、资源总价值及有效伤害任务。
- 基础攻击、防御与短程接近敌人；保护期间不攻击，最近的保护目标会挡住后方目标，墙不阻挡普通攻击。
- 区分本回合攻击风险与移动后的风险：不会用移动后的安全位置抵消本回合已经受到的攻击。所有可选动作都预计致死时，仍比较同时攻击可能带来的收益。
- 阵亡等待，按实际坐标恢复；同 Tick 返回缓存，旧 Tick 不提交，新场次清理目标，拒绝已退场场次的迟到消息。
- 可接收已校验、按场次和时间标记的效果快照：移动反转、强制等待、易伤、反伤；临时阻挡按有效期处理。
- 返回英文原因码和估计目标，便于日志和学习。`utility` 是内部排序值，不是预计实际得分。

## 当前边界

本目录保持标准 C++，ROS/JSON/libcurl 和模型结构校验实现放在 `../rmtc_ws/src/rmtc_bot/`。效果快照由底座的异步模型适配层提供；测试里的效果是人工构造案例，不是模型理解或正式 AI 资格证明。当前没有真实 API 验收。

尚未完整实现带时间维度的爆炸逃生、辣椒触发、堡垒群攻、回血等全部事件机制，也没有完整比赛仿真。当前攻击风险按可见敌人可能开火进行估计，敌人的下一动作、防御和移动都不能被保证。进攻/生存/任务采集只是不同权重，不保证某种模式一定最优。

任务收益使用标准计分上限 120 资源价值、500 有效伤害（v1.1）。若正式公告修改计分基准，需要调整配置实现。任务数量和坐标取输入；普通/高价值资源的进度只有适配层能从合法历史推断时才提供，实际完成与分数以裁判为准。

`examples/grid_planner.hpp` 只供本地演示与测试；生产适配已接 `../rmtc_ws/src/rmtc_bot/src/planner.cpp`。示例地图中未知格被当作可走，仅是测试假设。

## 在 Ubuntu 上构建

需要支持 C++17 的编译器和 CMake。Windows MSVC 与 Ubuntu G++11/CMake3.22 均已实际编译；本目录41个场景通过。完整集成工程另有57个场景，详细记录见 TEST_REPORT 和根目录集成说明。以下命令用于独立构建本模块。

```bash
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build -j 2
ctest --test-dir build --output-on-failure
./build/decision_demo
```

第一行准备构建目录，第二行编译，第三行运行验证，第四行展示五个场景。逐项解释在 `LEARNING.md`。本版使用标准库，不需要安装 JSON、ROS 或 HTTP 库来运行这些独立案例。

## 和底座怎么连接

底座实现 `Planner::plan()`，并把当前合法感知和地图记忆转换成 `GameState`。为同一席位保留一个 `DecisionEngine`，每个新回合调用 `decide()`；`submit=false` 时不发布，`submit=true` 时由底座给动作补上同一份感知的 `tick/session_id` 再发送。

`Decision.action.direction` 已经是要发给裁判的指令方向。幻术下，可能返回 `move down` 但 `expected_position` 位于上方，这是预期行为。底座不能再反转一次。

人工模式切换仍须遵守赛事登记和审批流程；不能因为 C++ 提供了三种模式就临场随意改参数。

# v0.2 集成更新

原有决策引擎现已接入 `../rmtc_ws/src/rmtc_bot/` 的 ROS/JSON 底座和生产 BFS；此目录仍可独立编译。新增时序路线 `Route.wait_first`、模型目标建议和带场次/时效的环境危险区输入。底座只传入校验后的结构，不在这里解析公告原文。旧 v0.1 源码压缩包保留为历史版本。


有效伤害直接使用裁判最新值，可下降、可为小数、可超过 500；不再次加击杀奖励或扣死亡惩罚。已完成任务以裁判 ID 为准。当前攻击收益仍为启发式估计，尚未预测多车分摊击杀奖励或辣椒/反伤奖励。
