# 10.0更新日志

基于9.3（98cd892），程序10.0.0，ROS包/程序仍rmtc_bot9。

- 新增resource_race.hpp：公开信息下的到达时刻估计、到达时间折扣及有界候选路线搜索。保留原路线已知资源、路线不更长、首资源领先且预计收益差明显时才替换，未声称最优或真实概率。
- 开局紧迫资源在足够血量、无当前预计来火、非补刀且无事件冲突时可以参与路线/攻击比较；不固定禁攻tick。
- 资源/任务达标且低血量时增加封顶后的火线风险代价；移动不规避本tick攻击。
- 第一阶段尾盘18tick以内重算已知资源路线预算；开发中强制跳过观察点的退步方案已撤回。
- 增加逐tick动作、回执种类、资源ETA与原因诊断。新增receipt_audit.hpp，区分回执异常和感知跳帧，不自动归因网络。
- scripts/audit_bag.py只读SQLite录制，独立CDR解码检查场次/tick/动作/回执；新测试及历史9.2数据检查发现tick25 move/wait差异，原因仍未知。
- 修复干净仓库缺默认配置及安装目录：分发decision_default.json并更新run.sh；启动核对实际执行路径并记录哈希，仍不伪装成完整二进制来源证明。
- 冻结9.3用于同地图对照；工具明确识别10.0/9.3/9.1，拒绝不存在的9.2别名，避免将旧版误测为当前版。
- 新增到达时间、尾盘、可见竞争、场次/回执种类及只读bag测试；继承规则与生产节点替身测试。历史证据单独归档，旧成绩不移记为本版。

更激进的竞争折扣、宽松路线替换和尾盘强制采集均有退步记录，已撤回；最终方案均分基本持平，只保留受约束的改动和完整验证工具。
