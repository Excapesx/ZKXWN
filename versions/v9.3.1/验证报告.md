# 9.3.1 工程整合与验证报告

2026-10-31，按用户要求将9.3策略与10.1.2工程接入整合。基线源码来自当前仓库eee4e1e；9.3.1为本项目指定最终版本。原9.3、10.1.2保留。

## 移植范围

- 保留9.3的采集/资源估值、路线算法、战斗收益和560伤害缓冲策略；未迁入10.1.x的固定时段乘数或2000伤害持续追击。Bot实现只加入10.1.2的任务点一次安全原地结算，以及对应去重/跨场重置状态。
- 使用10.1.2的ROS节点和异步LLM客户端/HTTP传输：官方默认模型、thinking disabled、JSON object、默认512输出预算、配额调度、超时和有限重试、跨场清理、席位错配告警、异常动作回退。令牌只从环境读取，不记录完整网关及密钥。
- 保留最新字段/事件合法性校验和last_action动作类型解析；新增ReceiptAudit诊断。删除仅10.x决策核心才有的分时/资源竞争日志字段，防止伪造诊断，不影响动作。
- 继承build/run/contest/doctor、运行身份与manifest校验等实际存在的脚本；登记队名可用RMTC_TEAM_NAME保留；第一阶段A席限制、第二阶段官方网关/令牌按启动提示填写。
- 资源任务/到点任务继续按missions及completedIds处理，不硬编码正式地图目标。默认balanced，ROS包和可执行程序仍是rmtc_bot9。
