## 在克隆的仓库中运行

需要Ubuntu 22.04、ROS 2 Humble、C++17、colcon和libcurl开发依赖。下列命令基于仓库放在`~/ZKXWN`：

```bash
cd ~/ZKXWN/versions/v1/01_程序源码/ZKXWN
bash ./scripts/build.sh
bash ./scripts/test.sh
bash ./scripts/run.sh A 2
```

`cd`进入本版的程序目录；`bash`执行对应Shell脚本。`test.sh`是检查，`build.sh`是构建，`run.sh A 2`启动A席位第二阶段；第一个参数可改席位，第二个参数`1/2`代表阶段。裁判需要另行启动，公开ROS域及网关按现场要求配置，不能据启动成功认定获得真实AI资格。本版测试脚本先要求ROS环境。

切换版本前先停止旧节点，避免同一席位多个程序同时发动作。真实令牌只放运行环境，不提交仓库。
