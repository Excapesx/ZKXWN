## 在Ubuntu中开始

把01_程序源码中的ZKXWN整个目录复制到Ubuntu主目录；若已有同名仓库，先比较或另存，不覆盖本地修改。

```bash
cd ~/ZKXWN
source /opt/ros/humble/setup.bash
./scripts/build.sh
./scripts/test.sh
```

如果从Windows复制后出现“权限不足”，先运行 `chmod +x scripts/*.sh`，意思是允许执行scripts目录里的Shell脚本。

四行分别是：进入仓库（~表示主目录）；加载ROS环境；编译程序；执行已有测试并汇总结果。
构建依赖与运行命令见程序根README.md。裁判练习包单独按v1.1教程安装，不要让策略读取练习全图或隐藏配置。
