# 第三轮分时影响审计

核对起点：未提交的10.3文件系统，928项交付清单、929文件完整摘要与holdout_v2源码冻结全部通过。清单与原字节存在本work目录baseline_v103_full_manifest.json；冻结核心在候选baseline_v103内，仅命名空间/include从rmtc9替换为rmtc103，不从Git HEAD漏取未提交基线。

|类别|实际位置与行为|本轮处理|
|---|---|---|
|数值：资源|phase_policy开局resourceScale=1.20；resource_priority_scale还检查生命、资源封顶、来袭伤害、无双和补刀窗口|C0原值、C1偏离1缩半、C2置1；所有原资格条件不变|
|数值：追击|openingFocus或endgame且有可得分目标时，hunt/intercept/sighting_search/seek乘0.70|仅插值数值，触发条件不变|
|数值：坐标任务|任一任务未完成，剩余<180为1.80、<90为2.60，作用于reach候选|仅插值数值，严格阈值不变|
|结构：开局路线|stage2_route_goal在openingEnd后关闭，且受视野、地图面积和remaining限制|保持10.3字节级原条件，不关闭kUseFixedPhases|
|结构：模式选择|openingFocus、collectionWindow及其攻击阈值2.0/1.25，观察回退/hasResourcePlan等|同状态探针逐帧核对一致|
|其他时间行为|kSeekFrom=40巡逻启用、kHiddenDecay=60隐藏资源先验衰减、记忆新鲜度、猎杀冷却等|不是指定三类乘数，本轮全部固定|
|非分时偏好|路线kRouteBoost=1.2、目标坚持1.12、竞争折扣、aggression、封顶后的denialScale=.25|不插值；其中路线加成的适用候选仍受原时间门槛控制|
|约束|总Tick预算、任务可达性、事件生效/保护/强制等待、动态安全|始终保留|

资源加成在collection_gain中进入stage2_route_goal资源候选价值及其路线搜索，不能假定只改变最终排序。因此日志标记route_view/route_collect的候选生成依赖；如果没有同路线的可信未加权优先级，before_phase_valid=false，禁止假造可逆原值。全状态复制探针独立重算整次决策，并比较候选集合、共享候选顺序、胜出路线、目标和动作。

g.score还影响既有delayAuxLoss上界，乘数可能通过该辅助成本发生间接作用；原公式保留，日志单列delay_aux_loss。旧phaseAux混合了其他辅助偏好，不能将该字段直接等同三类分时增量。新增phase_before/after只描述已知的数值施加点，最终priority和三类完全重算的同状态结果一起核验。

离线PhaseProbe在本帧被实际机器人消耗之前深复制Bot（包括历史地图、目标记忆、回执和计划）；分别注入1/.5/0并计算，不改变实际Bot。生产ROS固定RMTC_ENABLE_PHASE_PROBES=0，探针头文件在该设置下编译报错，未加环境变量、ROS参数、模型调用或通信动作字段。C0与冻结10.3另做真实逐帧动作恒等检查。

不启用删除时间开关的额外结构实验。本轮仅验证指定三类数值偏好，C2仍有原时间门槛，不能称其为完全不依赖时间的策略。
