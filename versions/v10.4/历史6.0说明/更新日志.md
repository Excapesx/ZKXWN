# 校内6.0更新日志

2026-10-24。程序基于5.0审阅，第二阶段移除5.0的长集合路线候选，保留4.0的成熟入口和既有规则防护。官方材料版本不变，仍为v1.1。

## 目标与资源

- 以当前可见信息和合法地图记忆逐帧重规划，最多比较两站短程资源组合，折扣可能被竞争者先取得的后续收益。
- 使用障碍感知的距离估计争夺资源；对能抢到的近距离竞争点增加偏好。
- 逐个任务ID考虑普通资源、高价值资源、资源总值和伤害任务，已完成ID不再奖励。资源分封顶后仍能继续完成任务。
- 加入明确的资源剥夺偏好和信息探索偏好；它们是启发式偏好，不冒充裁判直接加分。
- 第二阶段可留在脚下资源上收集。第一阶段采集算法保留，独立测试与4.0、5.0持平。

## 战斗与跟踪

- 新增battle.cpp：暂不攻击、集中攻击我方、选择攻击机会三种情景，每辆敌车每种情景最多一个动作。
- 按同一伤害批次计算过量伤害、去重击杀奖励、反伤和本车死亡扣除；先应用已知前置事件，再判断谁还能射击和挡枪。
- 按场景存活情况计入伤害任务估值，不再混用不相容的攻击分摊和受击假设。
- 当前防御或移动都无法保命时，不再直接丢弃负收益但能减少损失的攻击。
- 近期敌人位置会过期，当前完整视野发现其不在则立即撤销记忆。增加短期运动方向拦截、追击冷却和两格射击站位偏好，均属于预测。
- 原有幻术只反转移动、当前必死事件不能靠随后移动逃离等修复保留。

## 输入、工程与验证

- 拒绝同帧重复敌方队伍，避免多次计算同一车辆。
- 资源签名使用无符号运算；新场次清空敌人记忆、追击状态和旧动作状态。
- 命名空间rmtc6，ROS包/程序rmtc_bot6，版本6.0.0；构建、启动和对比脚本同步。
- 沿用并检查既有异步LLM工作线程；没有新增真实模型接入或取得正式AI资格。
- 对抗工具补移动回执、复活标记、阵亡无视野、基线保护期动作、全席位轮换、逐局JSONL和按地图聚类置信区间。
- Release、Debug各3992项断言零失败。第二阶段独立对比5120局，对称性432局，第一阶段200地图对；源码冻结摘要与逐局结果随包。
- “低血量提前撤退”方案在开发测试中降低得分，已移除。开发记录与最终验证分开保存。

## 仍未完成

Ubuntu ROS/curl完整构建、真实网关、官方裁判回执/换场次、随机事件全场和正式AI资格均待验收。单挑优势证据不足，四人局优势也不能当作任何对手、任何地图下的必胜保证。没有将6.0推送到GitHub。
