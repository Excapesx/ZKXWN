# v10.1se 更新日志

2026-10-30，从 10.1.1 复制开发。

## LLM 语义兜底

- LLM 输出新增可选 `mission_goals`，只接受五种官方任务：
  `normal_resources`、`high_resources`、`resource_value`、`effective_damage`、`reach`。
- 只有感知中的结构化 `missions` 为空时才启用；结构化任务非空时完全忽略模型任务。
- `reach` 校验坐标边界；其他类型校验正目标；未知类型、重复 ID、越界条目丢弃。
- 任务兜底最多 8 条；解析失败不会掩盖事件解析失败，坏事件仍会触发有限重试。
- Prompt 增加 `structured_missions` 和五种任务类型说明；事件 schema 增加 8 种 v1.2 事件别名。
- 日志新增 `mission_fallback=0/1` 和任务候选数量。

## 验证

- CTest 16/16 通过。
- 新增 `v101se_semantic_fallback` 测试。
- 练习裁判 + 真实 ROS 节点 + 本地 OpenAI 兼容服务：
  - `missions=[]`：`mission_fallback=1`，模型 3 条任务生效，0 非法动作；
  - 正常结构化任务：`mission_fallback=0`，官方任务优先，0 非法动作；
  - 两组 `local_ai_success=1`。

## 未改变

- 不改变决策算法、资源/战斗权重、`decision_type`、动作合法性检查。
- 不新增运行时参数或环境变量。
- 不读取全图或其他队感知。

## 限制

未连接官方网关，未验证真实模型的 `mission_goals` 输出质量；未在正式 24×24 地图完成整局验收。本版不宣称提高平均分。
