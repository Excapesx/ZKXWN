# 校内3.0更新日志

日期：2026-10-23。基线：桌面HERO/校内2.0；它是用户提供的独立原型，并非已合入主仓库的版本。

## 可靠性修复

1. **场次与缓存**：2.0在判断session之前先比较Tick，新比赛Tick归零可能整场被丢弃；现在使用FrameGate先识别新场次，清空缓存，并拒绝已退休场次的延迟帧。同Tick仅重发当前场次动作。
2. **AI调用状态**：成功计数随场次重置；旧场次的请求结果、401和配额阻塞不能修改新场次。当前场次HTTP成功与解析有效计划分别记录，不把以前成功过当成本场资格。正式资格仍需查看裁判侧计数。
3. **解析重试**：模型返回HTTP成功但计划不合规时，保留旧计划并限次重试。仅认可具有hazards数组的计划；解析遇到类型错误返回失败，避免异常逸出ROS回调。
4. **线程退出**：停止标志改为atomic，条件变量可中断退避，真实curl传输增加取消回调和1MiB响应上限。将HTTP传输与线程调度分开，模拟传输可复用相同线程代码测试，未冒充真实模型。
5. **公告更新**：优先感知中的近期公告，避免只使用单条topic导致遗漏上下文；模型输入包含上一计划，过时请求不覆盖最新计划。模型保留历史的语义准确性仍需真实测试。
6. **网关路径**：自动为根地址补全/v1/chat/completions；禁止打印完整网关地址。无真实凭据随包发布。

## 决策改进

- 移植校内1.0/f2f6eae的纯函数战斗结算计算，归入rmtc2命名空间：同Tick正伤害按实际比例分摊、贡献队伍去重分60、先奖励后扣死亡60、D保留超过500的缓冲。
- 比较单独开火与可见竞争者共同开火的目标收益，取较低信用；普通攻击的预测净分考虑本Tick死亡。仅在预测存活时加入伤害任务收益。敌人是否真的开火未知，仍为局部上界情景。
- 删除“自身易伤使攻击别人伤害翻倍”的错误。现有计划不能表达逐敌车易伤，不猜测该状态；自身易伤用于估计自身受击。
- 根据攻击先于移动的规则评估普通攻击危险；防御采用减伤后的独立死亡检查。HP未致死时不沿用1.0的每点受伤高额惩罚。保留档位偏好与0.2击杀节奏启发式，明确不是官方分数。
- 危险区逐格保留多段[start,end)，不跨空档合并，当前生效的不同危险区伤害求和作为规划估计；可从危险起点计算逃离路径。探索移动也补齐幻术方向补偿，出生保护期间在决策层排除攻击，避免出口层反复改成wait而停滞。
- 配置错误拒绝启动；机器人身份不符的感知拒绝使用。第一阶段超过13目标仍为贪心，没有声称实现插入或全局最优。
